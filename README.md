# ChaloChale Travel App

Responsive Bootstrap frontend project.

Pages: `index.html`, `destinations.html`, `packages.html`, `booking.html`, `contact.html`, `about.html`, `signup.html`, `login.html`.

CSS: `css/style.css` | JavaScript: `js/script.js` | Images folder: `Images/`.

Open the project folder in VS Code and run `index.html` using Live Server. Internet access is required for Bootstrap, Font Awesome and sample photos.

Note: Signup, login, booking and contact forms are frontend demonstrations only. They do not create accounts, verify credentials, send messages, or store bookings. A backend and database are required for those features.
